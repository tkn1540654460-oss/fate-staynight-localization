# 常见问题

## VitaShell 显示 USB 已连接，而不是 FTP 地址

VitaShell 的 `SELECT button` 设置可能配置为 USB。进入设置，把 SELECT 的行为切换为 FTP，再按 SELECT。电脑与 PSV 必须处于同一局域网。

## FTP 能打开，但读取到的资源无法识别

普通 `ux0:/app` 视图可能仍是加密内容。在你拥有合法副本的前提下，使用 VitaShell 的 **Open decrypted / 解密打开** 功能，并从它临时提供的视图复制需要的文件。不要对原目录执行写入。

## `psvctl` 拒绝上传

这是预期的安全行为。目标必须位于：

```text
ux0:/rePatch/<TITLEID>/...
```

工具不会提供关闭这项限制的参数。

## FTP 超时或连接被拒绝

- 确认 VitaShell 仍停留在 FTP 界面；
- 确认 IP/端口与屏幕一致；
- 确认两台设备处于同一网络且没有客户端隔离；
- 重新运行 `./psvctl configure <IP> <PORT>`；
- 不要通过公网暴露 VitaShell FTP。

## 翻译模型改坏控制码

不要直接让模型维护 RAW 标记。先把控制码替换成 `⟦0⟧` 这类短占位符；返回后逐条核对编号、数量和顺序，再由本地程序恢复。失败的记录单独重试。

## 批量翻译很快触发额度

降低并发、减少重复提示词、只发送相关术语，并采用检查点。服务报告配额重置时间时暂停请求，恢复后继续。不要在额度耗尽时进行高频重试。

## 中文显示为乱码或方框

脚本编码成功不代表字体包含对应字形。检查编码槽位映射、全部字号/字体档案是否同步更新，以及译文中的字符是否全部落在映射表中。

## 游戏启动崩溃

先移走 `ux0:/rePatch/<TITLEID>/` 下本次补丁恢复原状。然后按以下顺序定位：容器能否重新解包、文件表偏移/长度、脚本压缩、控制码数量、编码合法性和字体档案结构。
